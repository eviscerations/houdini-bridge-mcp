## [0.1.0] — 2026-08-06

First public release. Data-only, security-first MCP for **Houdini 21.0.671**.

### Added
- Data-only, security-first MCP for **Houdini 21.0.671**: a fixed registry of **1,467 typed,
  schema-validated tools** across acquire · terrain/heightfield · model · cleanup/mesh ·
  instance/scatter · simulation (FLIP/Pyro/RBD/Vellum/POP/MPM) · character animation
  (KineFX skeletons & rigging · Crowd · Muscle) · COP/image compositing · look/materials ·
  render/export · ML/ONNX · SideFX-Labs (tree/biome/world-building) · analysis · scene/utility ·
  weather/ocean. No arbitrary-code, generic-node-driver, or raw-VEX path.
- **Validated safe-VEX lane** (`set_attrib_expr`, default-off, executor-gated by `allow_attrib_expr`)
  plus the read-only `vex_reference` handoff — AI-assisted, human-gated VEX (never arbitrary code).
- **Operational recipe / router layer** (`recipe_reference`): a `classify` → lane → entry-recipe
  routing table plus 75 tool-mapped recipes, each with per-step landmark / verify / geometry_out and
  `wrangle_opportunity` cues.
- **Provenance-gated terrain downloader** (USGS 3DEP / TNM, state & global DEM) — https-only with a
  trusted-host allowlist and redirect re-validation; no arbitrary-URL import.
- **Rust MCP gateway + eframe launcher GUI** with a live audit log, plus an auto-arm Houdini package.
- **Third-party attribution** (`THIRD-PARTY-LICENSES.md`, generated by cargo-about) and dual
  licensing: PolyForm-Noncommercial-1.0.0 (free) + a separate commercial license.
- **`batch` meta-tool** (native): run up to 64 ops in one MCP call to cut per-call latency. Each op is
  dispatched through the exact same lookup + schema-validation + path-confinement + audit path as a
  direct call (no bypass), runs in order, continues on error unless `stop_on_error`, and cannot nest.
- **Optional action throttle** (`HMCP_MIN_ACTION_INTERVAL_MS`, default off): paces destructive tools
  (`delete_node`, `save_scene`, `delete_keyframes`) with a short sleep so a runaway loop or injection
  can't rapid-fire scene destruction. It slows, never rejects; non-destructive tools are unaffected.

### Security
- Compile-enforced data-only boundary — `catalog_never_exposes_rce_tools` and
  `safe_vex_is_the_only_code_path` fail the build if an RCE-shaped tool or a non-validated code param
  ever appears.
- Working-directory **path confinement** enforced on BOTH the gateway and the executor (realpath jail
  that resolves junctions/symlinks; the executor never trusts the gateway alone).
- **Cloud CI runs the security-critical paths without a Houdini license**: the safe-VEX validator's
  62-case red-team corpus and the `confined_path` traversal + symlink-escape tests.
